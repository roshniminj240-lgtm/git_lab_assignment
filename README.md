# Git Lab Assignment

This repository demonstrates the basic concepts of Git and GitHub.

## Objectives
- Initialize a local Git repository
- Create and manage files
- Commit changes using Git
- Push the project to GitHub

## Tools Used
- Git
- GitHub

## Steps Performed
1. Initialized a Git repository using `git init`
2. Created a file (file.txt)
3. Added the file using `git add`
4. Committed changes using `git commit`
5. Connected to GitHub repository
6. Pushed code using `git push`

## Conclusion
This lab helped in understanding the basic workflow of Git and GitHub.
